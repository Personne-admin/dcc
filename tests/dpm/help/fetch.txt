usage: dpm fetch [options]

Downloads and verifies the packages and assets named in project.lock.dcon so
that later builds and tasks work offline.

options:
  --manifest-path <file>    use this project.dcon instead of the one in the
                            current directory. The file must be named
                            project.dcon; dpm works in its directory.
  --offline                 never use the network; use only what is in the
                            cache. The same as DPM_OFFLINE=1. Something that
                            is missing from the cache is an error (exit code
                            5).
  --refresh                 ignore the 24-hour freshness window of cached
                            registry files

exit codes:
  0                         success
  1                         a build or test failed, a precondition was not
                            met, or a file could not be written
  2                         usage error
  3                         invalid manifest, lock or configuration file
  4                         resolution or integrity error (conflicting
                            versions, hash mismatch, registry problems)
  5                         network error, or something is missing from the
                            cache while offline
